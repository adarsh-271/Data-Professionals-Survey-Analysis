# Data Professionals Survey Analysis | Power BI

## Project Overview

Developed an interactive Power BI dashboard to analyze survey data from 630 data professionals, exploring salary trends, job roles, career transitions, programming language preferences, and workplace satisfaction.

## Tools Used

* Microsoft Power BI
* Power Query
* Microsoft Excel
* Data Visualization

## Project Objectives

* Analyze salary distribution across different job roles.
* Identify popular programming languages among data professionals.
* Examine career transitions into the data industry.
* Evaluate job satisfaction and workplace preferences.

## Key Insights

* Data Analysts represented the largest group of survey respondents.
* Python emerged as the most preferred programming language.
* Salary and work-life balance were important considerations among professionals.
* Many respondents had transitioned into data-related careers from other fields.
